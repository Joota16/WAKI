# Anexos de imágenes

[← Evidencias](../evidencias.md) | [Índice](../README.md)

Material de apoyo del proceso de Design Thinking. Cada archivo se nombra con su ID de evidencia (por ejemplo, `obs-01-f01.jpg`). ANX-01 a ANX-07 conservan la numeración de los anexos de la Ficha Técnica. Las imágenes de una misma funcionalidad se agrupan en un collage.

La [guía de entrevista y la plantilla de consentimiento](guia-entrevista.md) también forman parte de los anexos.
